# LINE スタンプ自動生成システム

セリフCSVから、LINE Creators Market へ提出できる透過PNGスタンプ一式（スタンプ画像・メイン画像・タブ画像・ZIP）を自動生成するローカルCLIツールです。

```
セリフCSV → プロンプト自動生成 → 画像生成API → キャラクター画像
  → 日本語テキスト合成(Pillow) → LINE規格へリサイズ → 透過PNG化
  → 余白チェック → 容量チェック → main/tab画像 → 提出用ZIP → gallery.html
```

**設計の要点**

- 画像生成AIには**日本語を一切描かせません**（誤字・文字化け対策）。AIは「キャラクター＋ポーズ＋表情」だけを描き、セリフは後処理で Pillow により合成します。
- キャラクターの一貫性は **`data/character/character_master.png`（マスター画像）を参照画像としてAPIへ渡す**方式で確保します。マスター画像を差し替えるだけで別キャラクターのスタンプセットを作れます。
- 画像生成は Provider 抽象化されており、将来 Gemini / Stability などへ差し替えられます。
- APIコストを守るため、キャッシュ・dry-run・範囲指定・リトライ・途中再開を標準装備しています。

## 4. キャラクターマスター画像の準備

`data/character/character_master.png` が基準画像です。**存在しない場合、システムは `character_master.pngがありません` と明示的にエラーを出して停止します**（勝手に100種類のキャラクターを生成することはありません）。

用意する方法は2つあります。

**A. 自分で用意する**（推奨・無料）

透過PNG・全身・背景なしのキャラクター画像を `data/character/character_master.png` に置いてください。`prompts/character_master.txt` のデザイン指定に沿った画像だと一貫性が高まります。

**B. APIで1枚だけ生成する**（API 1回 ≒ $0.01〜$0.17）

```bash
python -m src.main init-character --dry-run
```

```bash
python -m src.main init-character
```

生成された画像が気に入らない場合は `--force` で作り直せます。**このマスター画像の出来が100枚すべての品質を決めるので、納得いくまでここで作り込んでください。**

将来、別キャラクターのスタンプを作りたくなったら、このファイルを差し替えるだけです。

### キャラクターの特徴を日本語で書く

キャラクターの説明（マスタープロンプト）は **日本語で書けます**。

**GUIなら、ボタンを選ぶだけで説明文ができあがります（かんたん入力）。**「はじめに」タブの「キャラクターの特徴」で、次のように操作します。

1. 「ひな形から始める」で近いものを選ぶ（18種類。人／動物／そのほか に分かれています）
2. 性別・年齢・職業・頭身・髪型・髪の色・服装・服の色・体型・小物・雰囲気・配色を、気になるところだけボタンで変える（もう一度押すと解除）
3. 選択肢に無い特徴は「そのほかの特徴」に書き足す
4. 「この内容で保存」を押す

- 「動物」を選ぶと、髪型や職業など人間向けの項目は自動で隠れます
- できあがった説明文は直接書き換えてもかまいません。書き換えたあとは、選択を変えても説明文は自動で上書きされません（「選択内容で作り直す」で戻せます）
- 選んだ内容は `prompts/character_profile.json` に保存され、次に開いたときに復元されます
- 「会社員（男性）」は、同梱の説明文と一字一句同じ文章になります

ファイルを直接編集する場合は、`prompts/character_master_ja.txt` に1行に1つずつ特徴を書いてください。

#### ひな形の選び方の根拠（LINE人気ランキングの傾向）

ひな形のうち12種類は、LINE STORE のクリエイターズスタンプ人気ランキングの傾向を参考に追加しました。GUIでひな形にマウスを乗せると、それぞれの根拠が表示されます。

- 確認日: 2026-09-21
- 参照: [人気ランキング](https://store.line.me/stickershop/showcase/top_creators/ja)（1〜2ページ目・72件）、[新着ランキング](https://store.line.me/stickershop/showcase/new_creators/ja)
- 公式・版権キャラクター（アニメやゲームなど）は参考から外しています

| 傾向 | 追加したひな形 |
|---|---|
| ねこが最も多い。とくに「ふわふわ」「もちもち」「まるい」系 | ふわふわ子ねこ、もちもちねこ |
| ハムスター・うさぎなどの小動物 | ハムスター、ゆるうさぎ |
| トイプードル | トイプードル |
| シュール・口の悪いとり | ハシビロコウ、ツッコミことり |
| 大人女子・ていねいな気づかい言葉 | 大人女子（ていねい） |
| お嬢様・姫などのコミカルな女性 | お嬢様（コミカル） |
| おばあちゃんの言葉 | おばあちゃん |
| 白くて丸いふしぎなキャラ | ふしぎな白い生き物 |
| 食べ物キャラ（新着に多い） | パンのキャラ |

**参考にしたのは「どんな種類のキャラが人気か」という傾向だけです。** 特定の人気キャラクターに似せたひな形は作っていません。既存キャラに似たスタンプは、LINEの審査で却下されたり権利トラブルになったりするためです。ランキングは日々変わるので、ときどき見直すことをおすすめします。

```text
30代くらいの日本人男性の会社員。
2〜2.5頭身のちびキャラ。
短い黒髪。
白いワイシャツ。
シンプルな濃い色のネクタイ。
少し丸みのある体型。
親しみやすく、コミカルな雰囲気。
配色はシンプルにする。
```

- `prompts/character_master_ja.txt` に中身があれば、英語版（`prompts/character_master.txt`）より**優先**されます。英語版に戻したいときは、日本語版のファイルを空にするか削除してください
- 「背景透過」「全身」「枠・透かしなし」「文字を描かない」などの**技術的な指示は、英語のまま自動で付け足されます**。スタンプとして使えるかどうかに直結するので、AIが最も確実に従う英語で固定しています
- マスター画像の生成にも、100枚すべてのスタンプ生成にも同じ説明が使われます
- 実際にAIへ送る全文は、`python -m src.main preview --id 001 --full` か、GUIの「自動で付け足される指示と、実際にAIへ送る内容を見る」で確認できます
- 別のキャラクターに変えるときは、この説明を書き換えてから、マスター画像も作り直してください（参照画像として使われるため）

## 5. セリフCSVの編集

`data/stickers.csv`（UTF-8、100件収録済み）

```csv
id,text,action,expression,category
001,了解！,片手でびしっと敬礼する,自信のある笑顔,basic
```

| カラム | 内容 |
|---|---|
| `id` | 3桁の連番。出力ファイル名になります |
| `text` | スタンプに合成される日本語セリフ |
| `action` | ポーズ・動作（プロンプトに渡されます） |
| `expression` | 表情（プロンプトに渡されます） |
| `category` | 演出のトーン（`basic` `thanks` `work` `surprise` など） |

`text` は画像生成AIには渡されません。後処理でのみ使われます。

## 5-2. GUI（ブラウザで操作する）

コマンドを覚えなくても、ブラウザ上ですべての操作ができます。

```bash
python -m src.main gui
```

`http://127.0.0.1:8765/` が自動で開きます。**127.0.0.1 にのみバインドするため、このPCの外からは接続できません。** 終了は Ctrl+C です。

| オプション | 説明 |
|---|---|
| `--port 8765` | 待ち受けポート |
| `--no-browser` | ブラウザを自動で開かない |
| `--host` | 既定は `127.0.0.1`。変更すると外部に公開されるため推奨しません |

### 初めて使うとき：画面上部の「進め方」に従うだけ

**どこから手を付ければいいか迷わないよう、ページ上部に7ステップのガイドが常時表示されます。**
いまの状態（APIキーの有無・マスター画像の有無・生成済み枚数・ZIPの有無）を自動で判定し、
済んだステップは緑のチェック、いまやるべきステップは強調表示されます。

```
1 準備を整える → 2 キャラクターを決める → 3 まず1枚だけ試す → 4 文字の見た目を整える（任意）
  → 5 残りをまとめて生成 → 6 LINE仕様を検証 → 7 提出用ZIPを作る
```

その下の「**次にやること**」欄に、いま押すべきボタンが1つだけ出ます。
たとえば初回なら「001を1枚だけ生成」ボタンが出るので、それを押せば始められます。

**前のステップにはいつでも戻れます。** ステップのカードを直接クリックするか、`← 前のステップ` / `次のステップ →` ボタンで移動します。完了済みのステップでも選べるので、「キャラクターを作り直したい」「セリフを直したい」といったやり直しができます。自分で選んだ状態は「選んだステップ」と表示され、`自動判定に戻す` を押すといまの状態に応じた表示に戻ります。

右上の「ガイド」ボタンで表示/非表示を切り替えられます（次回も記憶されます）。

各ボタンやスライダーには**マウスを乗せると説明が出ます**。「強制再生成って何？」「dry-runは課金される？」といった疑問はその場で解消できます。

### 画面構成

**はじめに**（ステップ1・2）
「準備」では、APIキー・日本語フォント・CSV・生成設定の状態と、問題があるときの直し方を表示します。
「キャラクター」では、**マスター画像の操作がGUIだけで完結します。**

- 現在のマスター画像を表示
- 手持ちの画像をアップロードしてマスターにする（PNG以外も受け付け、必要なら自動で透過処理します）
- **AIに1枚だけ作らせる**（`init-character` と同じ。実行前に料金確認あり）
- マスタープロンプト（`prompts/character_master.txt`）をその場で編集
- **履歴から元に戻す** — 差し替え時に前の画像を `character_master_<日時>.png` として必ず残すので、いつでも戻せます

すでにスタンプ画像がある状態でキャラクターを変えると絵柄が混ざるため、警告と「**いまの画像を退避する**」ボタンを表示します。退避は `output/archive/<日時>/` への移動で、**削除はしません**。

**スタンプ一覧**
100枚をサムネイルで一覧表示します。チェックボックスで選び「選択した画像を生成」。**実行前にAPI呼び出し枚数と概算コストが必ず表示され、確認ダイアログが出ます。** 既に原画があるものは自動的に除外されるので、二重課金は起きません。1枚ごとの「作り直す」ボタンで、気に入らない1枚だけをピンポイントで再生成できます。画像クリックで拡大表示。

**セリフ編集**
セリフ・ポーズ・表情・カテゴリを表形式で編集し、`data/stickers.csv` に保存します。上書き前に `stickers.csv.bak` を自動作成します。行の追加・削除も可能です。

**文字デザイン**
- **おまかせ提案**：「キャラに合わせて提案する」を押すと、キャラクター画像から**線の色・体の色・差し色**を読み取り、かんたん入力で選んだ**雰囲気**に合うフォントと組み合わせて、文字スタイルの候補を出します（例：体の黄色の文字＋線の焦げ茶の縁取り、極太フォント）。候補を押すとプレビューに反映され、「この設定を保存」で確定します。押しただけでは設定は変わりません
- **フォント**：このPCで使える日本語フォントから選べます（BIZ UDゴシック、UDデジタル教科書体、Noto Sans JP 極太、游明朝 など）
- **フォントを増やす（無料）**：Google Fonts の無料フォント14種類を、ボタン1つで追加できます。**押したときだけ**ダウンロードします（1つ0.3〜8.5MB）
  - 手書き：はちまるポップ、油性マジック、よもぎ、クレー、紅道、キウイ丸、だるまドロップ
  - 丸ゴシック：Zen丸ゴシック ／ ポップ：モッチーポップ、デラゴシック、ロックンロール、ポッタ ／ 毛筆：佑字 朴 ／ ドット：ドットゴシック16
  - ライセンスは SIL Open Font License で、**スタンプとして販売する画像に使えます**。ライセンス文も `fonts/` に一緒に保存します
  - 手書きフォントを追加すると、「おまかせ提案」でも優先して使われます
  - 自分で用意したフォントは、プロジェクト直下の `fonts/` に `.ttf` / `.otf` / `.ttc` を置けば一覧に出ます
- **足りない文字のチェック**：フォントによっては漢字などが入っていません。フォントを選ぶと、**セリフで使っている文字がそろっているか**を自動で調べ、足りない文字と、「□」になってしまうスタンプの番号を表示します
- **改行**：セリフは、何もしなくても「ありがとう／ございます」「よろしく／お願いします」のように**言葉の区切りで**自動改行します（言葉の途中で切れるのは、どうしても収まらないときだけ）。自分で決めたいときは、セリフ欄で**改行したい所で Enter** を押して「このセリフを保存」。「セリフ編集」タブでも同じように改行できます

フォントサイズ・縁取りの太さ・色・行数・テキスト帯の高さ・文字位置をスライダーで変えると、**その場でプレビューが更新されます。画像生成APIを呼ばないので何度でも無料です。**
**まだ1枚も生成していなくても使えます** — その場合はキャラクターマスター画像を代役にしてプレビューするので、1円も使う前に文字の見た目を決められます。 実寸（370×320）とLINE表示相当の小サイズも同時に確認できます。「この設定を保存」で `config/overrides.yaml` に保存され、「保存して全部に再適用」で全スタンプの文字を無料で貼り直します。

> 設定は `config/overrides.yaml` に差分として保存されます。コメント付きの `config/sticker_config.yaml` は書き換えません。読み込み時に上書きマージされるので、CLIにも同じ設定が反映されます。

**検証・出力**
バリデーション、main/tab画像の生成とプレビュー、ZIP作成とダウンロード、gallery.html 生成、`generation.log` の閲覧ができます。

### 進捗表示

生成中は画面下部に進捗バーとリアルタイムログ（ID・成功/スキップ/警告/エラー）と **API呼び出し回数** が表示されます。「中止」を押すと、実行中の1枚が終わった時点で安全に停止します。生成済み画像は残るので、そのまま再開できます。

GUIとCLIは同じパイプライン（`pipeline.py` / `image_generator.py` / `validator.py` / `package_builder.py`）を呼ぶため、どちらで実行しても結果は同じです。併用もできます。

### 7-5. 手持ちの画像を使う（APIなし・無料）

画像生成APIを使わずに、**ほかのツールで作った画像や自分で描いた絵**をスタンプの原画として取り込めます。取り込んだあとの文字入れ・LINE規格化・検証・main/tab・ZIP作成は、AIで作った場合とまったく同じです。**APIキーが無くても最後まで進められます。**

```bash
python -m src.main import path\to\images
```

- フォルダを指定すると、**ファイル名の数字をIDとして**取り込みます（`001.png` → 001、`sticker_12.jpg` → 012）
- 数字が無い・数字が2か所ある・CSVに無い番号のファイルはスキップし、理由を表示します
- PNG / JPEG / WebP / GIF / BMP に対応。背景が不透明な画像は、四隅の色を背景とみなして自動で透過を試みます
- 長辺2048pxを超える画像は自動で縮小します

1枚だけ取り込むなら `--id` で番号を指定できます。

```bash
python -m src.main import my_drawing.png --id 001
```

GUIでは「スタンプ一覧」の各カードにある「**画像を入れる**」、またはツールバーの「**手持ちの画像をまとめて取り込む**」から同じことができます。

> **既存の画像は消えません。** 取り込みや「強制再生成」で原画を置き換えるときは、前の画像を `output/archive/replaced/<ID>_<日時>.png` に退避してから置き換えます。

## 8. バリデーション

```bash
python -m src.main validate
```

各画像について以下を検証します。

- PNG形式であること / ファイルが破損していないこと
- 370×320px 以内、縦横が偶数であること
- 透過PNGであること、カラーモードが RGB / RGBA であること
- ファイル容量が 1MB 以下であること
- 画像が空でないこと
- コンテンツが画像端に接触していないこと（接触＝ERROR）
- 余白が10px以上あること（不足＝`WARNING: insufficient margin`）

余白はパイプライン側で自動的に確保されるため、通常は警告は出ません。

## 10. ZIP作成

LINEの1セットは **8・16・24・32・40枚** のどれかです。作り方は2通りあります。

**GUI**（「検証・出力」タブ）

| 作り方 | 内容 |
|---|---|
| **番号順に分ける** | 1セットの枚数を「おまかせ／40／32／24／16／8」から選びます。「おまかせ」は、できるだけ多く使えるように組み合わせます（100枚 → 40＋40＋16、残り4枚） |
| **選んだスタンプだけで1セット** | 「スタンプ一覧」でチェックを付けたものだけでZIPを作ります。気に入ったものだけで申請したいときに使います |

ボタンを押す前に、「40枚×2セットのZIPを作ります（001〜040 ／ 041〜080）。残りの20枚はどのセットにも入りません」のように**仕上がりが表示されます**。選んだ枚数が8・16・24・32・40枚のどれでもないときは、「あと3枚選ぶと40枚セット、5枚外すと32枚セットになります」と案内し、ボタンは押せなくなります。スタンプ一覧でも、ちょうど1セットにできる枚数を選ぶと「このまま1セットにできます」と表示されます。

**CLI**

```bash
python -m src.main package
```

```bash
python -m src.main package --set-size 40
```

```bash
python -m src.main package --start 1 --end 40 --set-size 40
```

- `--set-size` は `auto`（おまかせ・既定）／ `8` ／ `16` ／ `24` ／ `32` ／ `40`
- `output/main/main.png`（240×240）と `output/tab/tab.png`（96×74）も自動生成します
- ZIP名は `line_stickers_001_040.zip`（番号順）、`line_stickers_selected_40.zip`（選んだもの）
- ZIP内のファイル名は `01.png` … `NN.png` / `main.png` / `tab.png`。原画・ログなどの中間ファイルは含みません
- **作り直すと、前回のZIPは `output/archive/packages/<日時>/` に移します**（削除はしません）。分け方を変えたときに、古いZIPが混ざらないようにするためです

## 11. LINEへの申請方法

1. [LINE Creators Market](https://creator.line.me/) にログイン
2. 「新規登録」→「スタンプ」→「スタンプ」を選択
3. スタンプ名、説明文、販売エリア、テイストなどを入力
4. 「スタンプ画像」タブで `output/packages/line_stickers_001_040.zip` をアップロード
5. メイン画像・タブ画像がZIPに含まれているので自動で割り当てられます（個別アップロードも可）
6. 販売価格を設定して「リクエスト」→ 審査へ

審査には通常数日かかります。審査基準（著作権・肖像権・公序良俗など）は公式ガイドラインを確認してください。

### タイトル・説明文を自動で作る

GUI の「検証・出力」タブにある **「タイトル・説明文（申請用）」** で「自動で作る」を押すと、
キャラクターの特徴（かんたん入力）とセリフから、英語・日本語のタイトルと説明文の案を3つ作ります。
APIは使わないので無料です。案を選んで自由に書き換え、「コピー」で LINE Creators Market に貼り付けます。

- 英語の登録は必須です。日本語は「言語を追加」で登録します
- 文字数は LINE の数え方（**全角は2文字**）で表示します。タイトル40・説明文160・クリエイター名50・コピーライト50（英数字のみ）
- 絵文字・URL・「LINE」という言葉・発売日などの告知は入れられないので、入力中に警告します
- 複数のセットを申請するときは「どのセリフから作る？」でセットを選ぶと、セット2以降はタイトルに番号が付きます
- 保存先は `data/listing.json`（Git の管理対象外）

（文字数ルールは [制作ガイドライン](https://creator.line.me/ja/guideline/sticker/)、英語が必須なことは
[ヘルプセンター](https://help2.line.me/creators/web/categoryId/20002326/3/pc?lang=ja) で 2026-09-22 に確認）

## 12. API料金に関する注意

**本ツールは有料APIを呼び出します。実行前に必ずコスト概算を確認してください。**

`gpt-image-1` の 1024×1024 1枚あたりの概算単価（画像出力トークン課金・USD）:

| 画質 | 1枚 | 100枚 |
|---|---|---|
| `low` | 約 $0.011 | 約 **$1.1** |
| `medium` | 約 $0.042 | 約 **$4.2** |
| `high` | 約 $0.167 | 約 **$16.7** |

- これは概算です。実際の請求額は OpenAI の最新単価に依存します。必ず [公式の料金表](https://platform.openai.com/docs/pricing) を確認してください。
- 単価表は `src/providers/openai_provider.py` の `PRICE_TABLE_USD` に定義されています。値上げ・値下げがあればここを更新してください。
- **リトライも課金対象**です。失敗が続くと想定以上の課金になる可能性があります。
- 生成済み画像は自動的にスキップされるため、再実行しても二重課金は発生しません。
- 気に入らない画像だけを `--id` で個別に `--force` 再生成するのが最も経済的です。

**無料で使える画像生成APIについて（2026-09-21 確認）**
Google Gemini API の画像生成モデル（`gemini-2.5-flash-image` / `gemini-3.1-flash-image` / `gemini-3.1-flash-lite-image` / `gemini-3-pro-image`）は、[公式の料金ページ](https://ai.google.dev/gemini-api/docs/pricing)で**無料枠の画像出力が "Not available"** とされています。最も安い `gemini-3.1-flash-lite-image` でも1枚 約$0.034 で、OpenAI `gpt-image-1` の `low`（約$0.011）より高くなります。
料金をかけたくない場合は、セクション7-5の「**手持ちの画像を使う**」機能を使ってください。

コストを抑えるチェックリスト:

1. `--dry-run` でプロンプトを確認する（無料）
2. `IMAGE_QUALITY=low` で 001 を1枚だけ生成する
3. 良ければ 10枚、最後に 100枚
4. 文字レイアウトの調整は `render` コマンドで（無料）

## 18. トラブルシューティング

| 症状 | 対処 |
|---|---|
| `character_master.pngがありません` | セクション4の手順でマスター画像を用意してください |
| `OPENAI_API_KEY が設定されていません` | `.env` を作成し、キーを記入。`python -m src.main doctor` で確認 |
| `日本語フォントが見つかりません` | `config/sticker_config.yaml` の `font.path` に .ttf/.ttc の絶対パスを設定 |
| 文字が小さすぎる / 大きすぎる | `font.size` と `font.min_size` を調整し、`python -m src.main render` で無料で再合成 |
| 文字がキャラに重なる | `font.band_ratio`（テキスト帯の高さ比）を上げる。`font.position: top` で上寄せも可能 |
| 文字が3行以上になる | `font.max_lines` を増やすか、CSVのセリフを短くする |
| `WARNING: insufficient margin` | `sticker.margin` を確認。通常は自動で確保されます |
| キャラクターの見た目がバラバラ | マスター画像を作り直す／`prompts/character_master.txt` をより具体的にする／`generation.quality` を上げる |
| 背景が透過されない | `make_background_transparent()` が四隅の色から自動で透過を試みます。それでも駄目ならプロンプトの `Transparent background` を強調 |
| 容量が1MBを超える | 自動で減色されます。ログに減色の警告が出ます |
| `SKIP 001 - already exists` を回避したい | `--force` を付ける |
| Windowsで日本語が文字化けする | `$env:PYTHONIOENCODING="utf-8"` を設定してから実行 |
| ZIPが作れない / 枚数が合わない | LINEは8の倍数（最大40）単位です。セクション10を参照 |
| GUIが起動しない（ポート使用中） | `python -m src.main gui --port 8800` など別のポートを指定 |
| ターミナルに `GET /img/main.png 404` などが出る | エラーではありません。まだ作成していないファイルを参照しただけです。`package` を実行すると出なくなります |
| `--host` を付けたら警告が出た | 意図した動作です。`127.0.0.1` 以外は他の端末から接続でき、GUIから課金操作ができてしまいます。通常は `--host` を付けないでください |
| GUIで「すでに処理が実行中です」 | 生成は同時に1件だけです。進捗バーの「中止」を押すか完了を待ってください |
| GUIの設定変更がCLIに反映されない | `config/overrides.yaml` に保存されています。削除すれば既定値に戻ります |

## 19. 実装上のルール

1. APIキーはコードに書かない（`.env` のみ）
2. `.env` はGit管理対象外
3. 生成済み画像を自動削除しない
4. 原画（`output/generated/`）を上書き・破壊しない
5. APIを無駄に実行しない（キャッシュ・dry-run・範囲指定）
6. まず1枚 → 10枚 → 100枚の順で確認する
7. エラー時は途中から再開できる
